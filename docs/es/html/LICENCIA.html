Licencia — StartupPerks

Origen del proyecto

StartupPerks es un fork del repositorio original startup-perks creado por jnd0. El fork se mantiene en guspatagonico/astro-startup-perks.

Ambos repositorios están bajo la Apache License, Version 2.0.

Apache License 2.0 — ¿Qué significa?

Es una de las licencias open-source más permisivas y utilizadas (Linux, Kubernetes, Android, TensorFlow). Está diseñada para maximizar la libertad de uso mientras protege a los autores originales de responsabilidad legal.

Lo que PERMITE

Acción Detalle
Modificación Podés modificar, adaptar, traducir, o crear obras derivadas sin pedir permiso.
Distribución Podés distribuir copias del original o de tu versión modificada, en forma de código fuente u objeto compilado.
Uso de patentes La licencia incluye una concesión explícita de derechos de patente de los contribuyentes. Si alguien contribuye código y tiene patentes sobre ese código, te otorga licencia para usarlas.
Uso privado Podés usar el código internamente sin ninguna obligación de distribuirlo ni publicar cambios.
Sublicenciar Podés redistribuir el código bajo una licencia diferente, siempre que mantengas los avisos requeridos.

Lo que OBLIGA

Obligación Detalle

Archivo NOTICE Si el proyecto incluye un archivo NOTICE con atribuciones, debés incluirlo en cualquier redistribución.

Implicaciones prácticas para este fork

Lo que está bien ✅

  • Modificar el código libremente (ya se hizo: migración a Astro, nuevo diseño, cambios en el Worker)
  • Agregar nuevas funcionalidades (API de envíos, documentación, etc.)
  • Mantener el repositorio como fork público con atribución al original
  • Usar el proyecto con fines comerciales o no comerciales
  • Agregar contenido nuevo (perks, documentación) sin restricciones

Lo que se debe hacer 📋

  • Mantener el aviso de copyright de jnd0 en los archivos modificados
  • Incluir el archivo LICENSE completo en el repositorio
  • Indicar en el README o documentación que este es un fork con modificaciones
  • Si se usa un archivo NOTICE, mantener las atribuciones originales

Lo que no se debe hacer 🚫

  • Eliminar el aviso de copyright original de los archivos
  • Hacer pasar el trabajo derivado como si fuera enteramente propio sin reconocer al autor original
  • Usar el nombre del autor original (jnd0) para promocionar el fork sin permiso (esto es más una cuestión de trademark que de la licencia en sí)

Cláusula de patentes

La Apache 2.0 incluye una cláusula de terminación de patentes. Si un contribuyente inicia un litigio de patentes alegando que el Software infringe una patente, la licencia de patente otorgada por ese contribuyente se termina automáticamente. Esto protege a la comunidad de los llamados "patent trolls".
